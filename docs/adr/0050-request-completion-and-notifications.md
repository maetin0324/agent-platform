# ADR-0050: 依頼の成果を保ち、引き渡しを通知する

2026-09-20。人の修正依頼が調査へ縮小され、途中目標なしの完了が通知されなかった実機不具合への対応。ADR-0037/0038/0048 の該当規則を更新する。

- CoS の対話 run は軽量に保ち、明示された作業依頼を actions で委譲する。通常の修正・検証に方針の再承認を要求しない。調査は実装の途中であり、元の依頼が調査だけの場合を除き完了条件に置き換えない。
- actions から作る仕事に対話時点までの元依頼を決定的に保存し、レビュー条件に依頼との整合を追加する。会話の後続発言を古い仕事へ混入させない。
- 途中目標なしの通常仕事の完了も task_ready として、成果を確認できるタスクへのリンク付きで通知する。裏方は除外。完了は成果の引き渡しであり案件全体の達成を意味しない。
- 未決認可・質問は再起動後も対象。同じ仕事の再質問と同じ案件の次の返事は別の出来事として重複排除する。CoS の全体対話と active 案件も対象にする。
- 通知走査時刻を DB に保持し、再起動直前の完了・返事を取りこぼさない。初回導入時は過去の終端履歴を一斉送信しない。走査失敗時は時刻を進めない。
- 途中目標のレビューが失敗しても人の判断待ちを通知する。レビュー待ちは完了から5分まで猶予を置く。
- GUI のスマホナビは主要3画面とメニュー、全リンクは同じ定義から表示する。Console の重なり、一覧の題名消失、IME確定時の誤送信を直す。
